# Security policy

## Supported version

Security fixes target the latest commit on `main`. This project does not currently maintain older release branches.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/zubair-official/lead_finder/security/advisories/new). Do not open a public issue for a vulnerability.

Include a clear description, affected files or routes, reproduction steps, and the practical impact. Remove API keys, cookies, browser profiles, scraped lead data, and other personal or sensitive information from the report.

You should receive an acknowledgement within seven days. A fix timeline depends on severity and maintainer availability.

## Scope

Useful reports include command injection, path traversal, cross-site scripting, sensitive-data exposure, unsafe file handling, and ways an unauthenticated public deployment could be abused.

Requests to bypass CAPTCHAs, access controls, rate limits, consent screens, `robots.txt`, or other protective measures are outside the project scope and will not be implemented.
